数据结构说明

Supabase 建表 SQL：

create table treasure_maps (
  id text primary key,
  name text,
  author text,
  rows int,
  cols int,
  w int,
  h int,
  image text,          -- dataURL 或图片公网地址
  crowns jsonb,        -- [{r,c,x,y}]
  created_at timestamptz default now()
);
alter table treasure_maps enable row level security;
create policy "public read" on treasure_maps
  for select using (true);
create policy "public insert" on treasure_maps
  for insert with check (true);

自建 REST 接口约定：
GET 接口地址 → 返回数组；POST 接口地址（JSON body）→ 新增；DELETE 接口地址?id=xxx → 删除。
